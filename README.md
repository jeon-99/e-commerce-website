# Devfolk

A responsive React storefront for thoughtfully chosen everyday essentials in Bangladeshi taka (Tk). Browse the product collection, filter by category, price, or rating, sort results, and try the shopping bag and demo checkout.

## Run locally

```sh
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the Vite development server
- `npm run build` — create a production build in `dist`
- `npm run preview` — preview the production build locally
- `npm run lint` — run Oxlint

## Storefront features

- Responsive product catalog with category, price-range, and minimum-rating filters
- Featured, price, and rating sorting
- Shopping bag with quantity controls, subtotal, and free-shipping progress
- Demo sign-in, newsletter signup, and checkout interactions
- Product and editorial photography from Unsplash; typography uses Google Fonts
- Company details: developed by Jeon, Uttara Sector 11

Checkout is a front-end demo only. It does not process or store payment details.
